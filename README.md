# Mútua Educa+

Demo estática navegável para o Mútua Inova+ 2026, com dados mock.

- `index.html`: vitrine, busca, filtros e mini simulador.
- `curso.html?c=pavimentos`: detalhe e reserva de exemplo.
- `simulador.html`: crédito com cálculo pela Tabela Price.
- `meu-curso.html`: acompanhamento acadêmico e financeiro.

**Protótipo ilustrativo · valores de exemplo**

Abra `index.html` no navegador ou execute `python3 -m http.server` nesta pasta e acesse `http://localhost:8000`. Sem instalação ou build. Fontes e ícones precisam de internet. Os demais recursos são locais; os caminhos relativos permitem servir em subpasta.
